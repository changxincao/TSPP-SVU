# Synthetic input generation

Synthetic inputs are generated by `code/GenerateData.java`. `code/generate.py` reads the saved seed and configuration, runs the generator, and organizes its output into the repository layout.

## Demand parameters and covariates

For lane j,

`mu_j(x) = a_j + beta_jM*M + beta_jT*T + beta_jP*P + beta_jA*A`.

Draw `a_j ~ U(10,100)` and four independent positive coefficients `beta_jk ~ U(0,10*a_j)`. Covariate coordinates are ordered **M,T,P,A**: market state, time trend, promotion and attention. M, P and A are independent U(0,1) draws. Historical trend is `T_t=t/H`, with zero-based `t=0,...,H-1`; T=1 in every test decision context. To reproduce the random-number sequence, the generator draws four uniforms and replaces the second coordinate with the deterministic trend.

The procurement baseline is the historical nominal level:

`dbar_j = a_j + 0.5*(beta_jM+beta_jP+beta_jA) + ((H-1)/(2*H))*beta_jT`.

The saved `demand_parameters.csv` records this baseline.

## Residual distribution

A fixed U(0,1) lane quantile is mapped to the configured CV interval. Each lane also has a fixed common loading `rho_j ~ U(0.3,0.5)`. Each period uses one shared G~N(0,1) and independent lane variables Z_j~N(0,1):

`z_j = rho_j*G + sqrt(1-rho_j^2)*Z_j`.

- **Normal:** `D_j=mu_j*(1+CV_j*z_j)`. If negative, redraw only that lane's independent Z_j, holding the period's G fixed. Thus mu and CV are **nominal pre-rejection** parameters, not exact post-rejection moments. Zero is not rejected.
- **Lognormal:** `v_j=log(1+CV_j^2)` and `D_j=mu_j*exp(-v_j/2+sqrt(v_j)*z_j)`. The multiplicative error has mean one and the specified lane CV.

Historical and OOS residuals use separate random streams. The conditional OOS demand samples consume the OOS stream sequentially across decision contexts, without resetting it for each context. All compared methods use the same historical observations, decision context and OOS demands. Changing the CV range may change the number of rejected Normal draws and subsequent residual-stream consumption; procurement parameters, nominal coefficients and covariate streams remain unchanged across the paired settings.

## Procurement parameters

1. Each carrier covers `round(0.5*J)` lanes, chosen by shuffling. Any uncovered lane is repaired by a donor-lane swap, retaining carrier coverage counts.
2. Draw lane base rates `rbar_j ~ U(20,100)`, persistent carrier factors `F_i ~ U(0.7,1.3)`, and local factors `L_ij ~ U(0.9,1.1)`. Eligible rates are `r_ij=rbar_j*F_i*L_ij`.
3. Eligible capacities are `q_ij=dbar_j*U(0.3,0.5)`.
4. Spot rates are `U(2,3)` times the lane's arithmetic mean eligible contract rate.
5. MQC quantities are `p_i=U(0.15,0.35)*sum_{j eligible}dbar_j`; the per-unit shortfall penalty `h_i` is the minimum eligible rate for carrier i.
6. Selection limits are `ceil(0.1*I)` and `ceil(0.8*I)`. Total carrier capacity, if needed, is the sum of eligible capacities.

The `eligible` indicator specifies whether a carrier can serve a lane. Transportation allocation is restricted to pairs with `eligible=true`.

## Seed derivation and exact reproduction

Initialize Java `SplittableRandom(caseSeed)` and take five signed long values, in order: demand parameters, procurement parameters, covariates, historical residuals and OOS residuals. These derived seeds are saved in `random_streams.json`. Modules use `java.util.Random` streams, with the fixed XOR salts in the source for common-factor and coefficient-structure streams. Random-number call order and Java shuffling are part of the generation procedure.

Main and volatility experiments use master seeds 20261021–20261025. Each performance setting uses 20261021–20261023. The performance experiment does not generate OOS demands. Historical trend spans all H observations in each setting.

Direct generation command:

```text
java code/GenerateData.java OUTPUT NORMAL CV_LOW CV_HIGH SEED I J H QUERIES OOS_COUNT SELECTION_FRACTION
```

`NORMAL` may be replaced with `LOGNORMAL`. `QUERIES` denotes the number of decision contexts. This command produces a TSV input for each context and a lane-parameter CSV. Use `python code/generate.py INSTANCE_PATH --output OUTPUT` to generate the data in the repository layout.
